# 数据与方法说明

更新日期：2026-11-08

V0.2 的主要变化：三维人台由程序化几何体改为 MakeHuman / MPFB2 基础人体与测量拟合，并加入东亚面部形态、无衣物平滑体表。

这份文档记录素尺 V0.2 中每一个数字的来源、计算方式和没有做的事。应用内“数据说明”只呈现摘要，这里是完整版本。

---

## 1. 数据分层

素尺把数据分成三类，界面上使用不同标签：

| 标签 | 含义 | 例子 |
|---|---|---|
| 实测 | 用户输入的数值，直接锁定 | 胸围 88 cm |
| 估算 | 由模型根据其他参数推算，可能误差数厘米 | 未填写的腰围 |
| 参考 | 标准或文献中的分类阈值、人群锚点 | BMI 24、腰围 85 cm |

没有来源的“标准三围表”没有进入模型。

## 2. 已核验的人群锚点

### 2.1 身高与体重

- 国家卫生健康委员会《中国居民营养与慢性病状况报告（2020年）》：
  - 18–44 岁中国女性平均身高 **158.0 cm**
  - 18 岁及以上中国女性平均体重 **59 kg**
- 国家体育总局《第五次国民体质监测公报》：
  - 20–24 岁女性平均身高 **160.6 cm**
  - 成年女性身高随年龄增长整体呈下降趋势

应用中的年龄身高曲线是根据上述两个公开锚点和平滑假设构造的近似曲线，并非官方逐年均值表：

| 年龄 | 参照身高均值 |
|---|---|
| 18–24 | 160.6 cm |
| 30 | 159.1 cm |
| 35 | 158.6 cm |
| 40 | 158.2 cm |
| 45 | 157.8 cm |
| 50 | 157.4 cm |
| 55–60 | 157.0–156.7 cm |

体重年龄曲线同样是近似：24 岁 57.5 kg、35 岁 60.0 kg、45 岁 61.5 kg。它只用于百分位参照，不会覆盖用户输入的体重。

### 2.2 健康阈值

- **WS/T 428-2013《成人体重判定》**
  - BMI < 18.5：偏低
  - 18.5 ≤ BMI < 24：正常范围
  - 24 ≤ BMI < 28：超重
  - BMI ≥ 28：肥胖
  - 中国女性腰围 ≥ 85 cm：中心性肥胖参考阈值
- **WHO 腰臀比与腰高比参考**
  - 女性 WHR ≥ 0.85：风险增加参考线
  - WHtR ≥ 0.50：风险增加参考线

这些阈值只用于提示，不构成诊断。BMI 不区分肌肉和脂肪，腰围也会随呼吸、时间和状态波动。

### 2.3 体脂率

默认使用 Deurenberg 公式估算：

```text
BF% = 1.20 × BMI + 0.23 × 年龄 − 10.8 × 性别系数 − 5.4
女性性别系数 = 0
```

- 页面标注为“公式估算”，并提示个体误差约 ±4%。
- 用户可在“更多实测”中填写自填体脂率（体脂秤、BIA、DEXA 等），填写后显示为“自填值”。不同测量方式的误差不同，应用不把自填值当作诊断结论。
- 自填体脂率会轻微改变 3D 体表厚度（低体脂略收窄、高体脂略丰满）；它不参与围度拟合，也不会反过来修改胸腰臀或 BMI 数字。
- 该公式不是中国人群专用公式，不能用于诊断或体成分管理。

## 3. 围度估算：模型而非官方均值

这是最容易被误读的部分。

GB/T 10000-2023《中国成年人人体尺寸》提供了中国成年人人体尺寸的标准体系，但本应用 **没有直接复用其百分位表**。原因是：

1. 标准正文的公开获取和引用存在限制；
2. 现有公开网页中流传的“标准三围”版本混杂，很多没有样本、年龄和测量定义；
3. 本应用需要的是随身高、体重、年龄、骨架、脂肪分布变化的连续模型，而不是一张固定三围表。

因此，V0.2 使用一组**公开人体测量文献常见区间校准的模型基线**，并把它明确标注为“估算”。

### 3.1 基线

在身高 158 cm、体重 59 kg、女性、30 岁的参考条件下：

| 指标 | 基线 |
|---|---|
| 胸围 | 86.0 cm |
| 下胸围 | 76.5 cm |
| 腰围 | 79.0 cm |
| 臀围 | 92.5 cm |
| 肩宽 | 38.8 cm |
| 大腿围 | 53.5 cm |
| 小腿围 | 34.0 cm |
| 上臂围 | 27.5 cm |
| 腕围 | 15.5 cm |

这些数值是模型参数，**不是官方公布的全国均值**。

### 3.2 缩放

以身高 158 cm、体重 59 kg 为基准：

```text
身高因子 = (height / 158) ^ 0.72
体重因子 = weight / 59
```

各围度大致按以下弹性缩放：

| 围度 | 身高指数 | 体重指数 |
|---|---|---|
| 胸围 | 0.72 | 0.30 |
| 下胸围 | 0.72 | 0.25 |
| 腰围 | 0.72 | 0.52 |
| 臀围 | 0.72 | 0.35 |
| 肩宽 | 0.80 | 0.10 |
| 大腿围 | 0.72 | 0.30 |
| 小腿围 | 0.72 | 0.18 |
| 上臂围 | 0.72 | 0.20 |

并叠加：

- 年龄：30 岁后腰围随年龄轻微增加；这是方向性假设，不是个体衰老预测。
- 骨架：小 / 中 / 大骨架影响肩宽、腕围和部分躯干宽度。
- 活动量：规律运动使腰围略低、臀腿与肩背略高；久坐方向相反。
- 脂肪分布倾向：臀腿型降低腰围、提高臀腿围；腰腹型相反。所有修正都乘一个与 BMI 相关的幅度系数，避免在极瘦或极重时产生夸张变化。

### 3.3 实测覆盖

用户填写的每一项围度会在估算后覆盖对应值。所有覆盖项在界面上标为“实测”。围度之间的明显矛盾（如下胸围不小于胸围、腰围大于臀围）会保留原始输入并显示提示，不会自动“修改得更好看”。

### 3.4 模型误差

公开文献中不同年龄、地区、测量定义带来的围度差异通常在数厘米量级。V0.2 不提供逐项置信区间，只在界面上明确区分“实测 / 估算”。如果用途要求高精度，请使用软尺按标准位置测量，或使用专业人体测量设备。

## 4. 情境预览

生活状态只做方向性修正，不是个人预测：

| 状态 | 腰围 | 臀围 | 胸围 | 体重 |
|---|---:|---:|---:|---:|
| 日常 | 0 | 0 | 0 | 0 |
| 运动后 | −0.5 cm | +0.4 cm | +0.3 cm | +0.15 kg |
| 久坐日 | +1.0 cm | +0.35 cm | +0.1 cm | +0.2 kg |
| 经期 | +1.6 cm | +0.5 cm | +0.4 cm | +0.7 kg |
| 产后恢复 | +2.0 cm | +0.8 cm | +0.4 cm | 0 |
| 围绝经期 | +2.2 cm | −0.4 cm | +0.3 cm | +0.2 kg |

这些数字表达“短时水潴留、胀感或阶段性的脂肪重分布”可能带来的幅度，主要来自一般生理常识和公开科普材料，不是经过系统评价的效应量。**它们不代表每个人，也不预测未来。**

“产后恢复”和“围绝经期”是敏感阶段，应用只呈现方向性差异，不提供恢复目标、训练方案或治疗建议。

## 5. 百分位

V0.2 没有使用官方完整的百分位表，而是用正态分布近似：

- 身高：按年龄段均值，SD ≈ 5.8 cm
- 体重：按年龄段均值，SD ≈ 9.8 kg
- BMI：均值 23.6，SD ≈ 4.1
- 胸围：按身高缩放后的均值，SD ≈ 6.3 cm
- 腰围：按身高缩放后的均值，SD ≈ 9.4 cm
- 臀围：按身高缩放后的均值，SD ≈ 6.4 cm

百分位在 1–99 之间截断。界面明确写“估算参考，不是官方百分位表”。

身高和体重百分位的锚点来自官方报告；围度百分位来自模型假设，可靠性更低。

## 6. 地域数据为什么没有启用

用户可以选择地域，但 V0.2 **不根据地域改变模型或百分位**。原因是：

- 缺少可公开核验、覆盖“性别 × 年龄段 × 地区”的围度统计；
- 网络上流传的省份身高表往往没有抽样方法、年份和测量定义；
- 用几个省份的身高差直接推算三围，会产生虚假精度。

因此，地域当前只作为档案标签。应用内会显示“区域基线待核验”。这是一个明确的数据缺口，不是遗漏。

后续只有在找到可引用的区域调查或监测数据后，才会启用地域修正，并附上样本量、年份和限制。

## 7. 2D 与 3D 的生成

### 2D

SVG 正视图使用统一比例尺：

```text
scale = (floorY - topY) / heightCm
```

头、颈、肩、胸、腰、臀、腿、脚的控制点由输入围度和腿长决定。测量线标记胸围、腰围、臀围、肩宽和腿长。

### 3D

V0.2 不再从圆柱、球体和横截面放样拼装人台，而是使用成熟的开源参数化人体基础网格。

#### 基础资产

- 网格：MakeHuman hm08 基础人体（14,517 顶点，26,756 三角形）。
- 形态目标：MPFB2 的稀疏 morph targets。
- 来源：`naver/anny` 的 CC0 数据；本项目的原始输入与许可保存在 `assets/parametric-base.glb`、`assets/LICENSE-CC0.md`。
- 许可：CC0 1.0 Universal（公共领域）。不要求署名，本项目仍主动标注 MakeHuman / MPFB2 / naver/anny / three.ws。

#### 烘焙与压缩

- 以 `bodyFeminine = 0.7` 烘焙基础女性形态；
- 在头部与颈部顶点上叠加 `bodyAsian = 0.38`，让面部更接近东亚人特征，同时不改变身体围度拟合；
- 只保留与身体比例相关的 22 个形态目标：肩、胸、腰、腹、臀、臀围、臀肌、大腿、小腿、手臂、整体胖瘦与软组织；
- 去除眼睛、牙齿、舌头与完整骨骼/动画数据，仅保留用于姿态的轻量蒙皮权重；
- 将基础位置量化为 Int16，形态增量保存为稀疏数据，打包成一个约 0.65 MB 的紧凑二进制资源；
- 生成脚本：`scripts/build_body_asset.py`，输出 `src/three/bodyData.ts`。

#### 测量拟合

拟合不是“按体重整体缩放”，而是逐步逼近目标围度：

1. 身高先按目标值归一化缩放；
2. 用胸、腰、臀的目标围度分别计算形态权重；
3. 应用权重后，对真实网格做三角面-水平面求交，得到截面凸包周长；
4. 用凸包周长与目标值比较，迭代修正形态权重；
5. 最后按输入腿长，对骨盆以下和以上做轻度纵向比例校正。

在实际浏览器验证中，默认参数（162 cm / 55 kg）的拟合结果约为：

- 胸围 85.67 cm（目标 85.67）
- 腰围 77.57 cm（目标 77.20）
- 臀围 91.77 cm（目标 91.77）

肩、大腿、小腿、手臂的形态目标使用同一思路但校准较粗，主要保证视觉方向一致；围度数字仍来自 `anthropometry.ts`，不宣称逐项毫米级匹配。

#### 姿态与渲染

基础网格本身包含完整人体表面。为避免呈现解剖细节，应用通过几何平滑与程序化着色处理：

- 不渲染任何衣物与毛发，呈现完整、无性征细节的平滑人台；
- 乳头区域使用局部法线平滑隐藏细节，保留胸部体积与比例；
- 骨盆区域做几何 Laplacian 平滑与局部法线平滑，隐藏生殖器细节，保留髋部与腿部轮廓；
- 头部保持无发人台，不引入毛发资产；
- 自然站姿用原始蒙皮权重/链权重带动手臂下垂、双腿并拢；
- 踮脚姿态让脚背下压、脚尖着地，并将整体视觉抬升到脚尖接触地面，不添加鞋型；
- 踮脚造成的视觉抬升不计入身高、围度或比例读数；
- BMI 低于 18.5 时自动叠加 bodyThinner 与轻微结构阴影，做低体重视觉精瘦；自填体脂率也会微调体表厚度，但都不改变任何读数。

这些平滑与姿态处理是渲染和几何示意，不是真实服装或人体扫描。

#### 比例校正和限制

- 相机默认正交投影，避免透视拉伸；
- 标准 A 姿，双臂自然张开，便于观察身体轮廓；
- 腿长校正限制在基础比例的 ±6%，避免为迎合输入产生夸张变形；
- 三维模型是**比例可视化**，不具备扫描精度，不能用于服装打版或医学测量。

## 9. 隐私

所有输入和计算都发生在浏览器本地。没有账户、没有服务器、没有上传。导出的 JSON / PNG 由浏览器直接生成并保存到本机。
